# Image Encryption and Compression Using LFSR and Huffman Coding

## Overview

This project demonstrates two key functionalities:

1. **Image Encryption and Decryption using Linear Feedback Shift Register (LFSR):**  
   - LFSR is used to encrypt and decrypt images using a sequence generated from a shift register.
   - The technique ensures secure image transmission while maintaining a high level of performance.

2. **Image Compression and Decompression using Huffman Coding:**  
   - Huffman coding is implemented to compress the image data by encoding the pixels into binary codes based on their frequency.
   - The algorithm is then used to decompress the image back to its original form.

## Features

- **Image Encryption and Decryption:**  
  - Securely encrypts and decrypts images using a pseudorandom sequence generated by LFSR.
  
- **Image Compression and Decompression:**  
  - Efficiently compresses image data using Huffman coding and restores it with minimal data loss.

- **Support for Various Image Formats:**  
  - The project supports common image formats like `.jpg`, `.png`, and `.bmp`.

- **Lossless Compression:**  
  - Huffman coding ensures lossless image compression, retaining original image quality upon decompression.

## Requirements

- .NET 5.0 or higher
- Required libraries:
  - `System.Drawing.Common` for image handling
